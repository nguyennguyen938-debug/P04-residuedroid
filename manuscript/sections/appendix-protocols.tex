\paragraph{Earlier protocol versions.} Where a protocol was revised, the earlier runs are kept and their outcomes were as
follows. Natural race, emulator: the first two protocols failed their link-shaping gate in pilots, so no final trial ran.
Rented phones: the first TLS run matched the rerun in every case except one Galaxy case whose shorter deadline ended
requests early; in both runs no fenced case accepted bytes after the acknowledgement. Cost sweep: the first protocol's
probes mostly missed the send window, and the second lost trials to the test receiver's timeout; their medians are in the
artifact. Label mutants: in the first protocol the fixture never re-aggregated after the re-grant, so M1 could not
trigger; M2 leaked and M3 failed closed as in the second. Commit-point race: in the pooled run the withdrawal's timing
within LTE uploads differed across arms, so an LTE rerun started the withdrawal process before every trial; the pooled
LTE cells are kept and reported. AirGuard during a donation: the first protocol failed its calibration gate; in the
second, a later analysis fix ended each trial's receiver window at the next trial of the same build, which lowered the
fenced count from \gaFenceRxFirst{} to \gaFenceRx{} (both versions in the artifact); the equal-buffer run failed two mechanism gates on
reading the send buffer before its final run. Phone cost: in the third protocol the phone dozed during the run, so the
fourth kept the screen on and Doze off.
